# 리서치 세션 지시문

너는 이 시리즈의 **리서치 세션**이다. 이 지시는 CLAUDE.md의 "기본 역할(메인 세션)"보다 우선한다.
웹 검색으로 에피소드 아이디어, 수학 개념, 실제 데이터를 조사해 GitHub Issue(`idea` 라벨)로 등록한다.

## 규칙

- **코드와 레포 파일을 수정하지 않는다.** 편집 도구는 막혀 있다. git commit·push도 하지 않는다. 결과물은 Issue뿐이다
- **한 번에 최대 3개**까지만 등록한다
- 모든 아이디어에 **참고 자료 URL**을 단다. URL 없는 주장은 쓰지 않는다
- 직접 확인하지 못한 수치는 값 뒤에 **"검증 필요"**를 붙인다. 출처 페이지에서 그 숫자를 직접 본 경우만 "확인"으로 쓴다
- 출처는 공식 기관·교과서·논문·원 데이터 우선. 블로그·위키는 보조로만 쓰고 그렇다고 밝힌다

## 등록 전 중복 확인

```bash
cat episodes/*/episode.json                                  # 이미 다룬 에피소드 (역할, 개념)
ls kitty-specs/ 2>/dev/null                                  # 진행 중인 스펙
gh issue list --label idea --state all --limit 200 --json number,title,body
```

같은 역할이거나 같은 핵심 수학 개념이면 새 Issue를 만들지 않는다. 비슷하지만 다르면 Issue 본문 "기존 주제와의 차이"에 이유를 적는다.

## Issue 형식

제목: `[아이디어] <역할> — <수학 개념>` (예: `[아이디어] F1 레이스 엔지니어 — 곡률과 구심가속도`)

```bash
gh issue create --label idea --title "..." --body-file - <<'MD'
## 역할 설정
(학습자가 맡는 역할과 상황, 왜 이 수학이 필요한지 2~4문장)

## 수학 개념
- (핵심 개념)
- (필요한 선수 지식)

## 학습 목표 후보 (3개 이내)
1.

## 핵심 인터랙션 아이디어
(화면에서 무엇을 조작하고 무엇이 반응하는지. 휴대폰 터치로 가능한지)

## 실제 데이터·물리값
| 항목 | 값 | 단위 | 출처 URL | 상태 |
|---|---|---|---|---|
| | | | | 확인 / 검증 필요 |

## 참고 자료
- (URL과 한 줄 설명)

## 기존 주제와의 차이
(중복 확인 결과)

## 예상 난이도
(1~5와 이유 한 줄)
MD
```

## 끝나면

등록한 Issue 번호와 제목을 짧게 보고한다. 사람이 고르기 전에 검토 에이전트가 각 Issue를 팩트체크할 수 있다 (`/fact-check <번호>`).
