### 4. Core Interaction

5단계는 진공으로 고정되고, 발사하면 포탄이 출발 직후 멈춘다. "0.5초 진행 ⏭"을 누를 때마다 포탄이 0.5초 날아가고 표에 한 줄씩 쌓인다. 4번 누르면 다음으로 넘어갈 수 있다 (그대로).

**지금**: 처음 누르는 순간 방금 조각 문장, 표, 표 설명, 🤔 의문, 이유 상자가 한꺼번에 나오고 이후에도 계속 함께 보인다.

**바뀐 뒤**: 방금 조각 문장과 표는 매번 그대로이고, 표 아래 설명은 **이번 누름에서 새로 나온 것만** 보인다. 앞 누름의 설명은 내린다 (사람 결정, DM-01M5VXNADX19C8ZNFNZ9EA6XFD).

| 누른 횟수 | 표 아래 설명 |
|---|---|
| 0 (발사 전 / 발사 직후) | 지금 그대로 |
| 1 | "🤔 그런데 첫 줄을 보세요. … 아래에서 이유를 볼게요." → 이유 상자 ("방금 조각: (a + b) ÷ 2 × 0.5 = … m" + 평균 설명) |
| 2 | "vy가 매번 약 **4.9씩** 줄어요 (중력 9.8 × 0.5초)." |
| 3 | "맨 오른쪽 칸은 조각들을 **전부 더한 값**이에요. 이게 적분이에요." |
| 4 이상 | (조각이 음수면) "조각이 음수가 됐어요! …" → "더 눌러 봐도 되고, 계속 ▶을 누르면 끝까지 날아가요." |

- 지금의 표 설명 한 문단을 2번·3번 두 문단으로 나눈다. 글자·숫자·강조·모양(작은 글씨)은 그대로다
- 순서가 Issue #10(표 설명 → 🤔 의문)과 반대가 된다. 의문이 첫 줄을 가리키므로 첫 누름에, "매번 4.9씩"은 줄이 두 개일 때 맞춘다 (사람 결정, DM-01M5VXN4XCFDWDXWVQ9B74J7QB)
- 음수 안내는 지금처럼 조건이 될 때 나온다. 기본 설정(vy0 ≈ 53.0)에서는 12번째 누름에 처음 나와 4번 이후 구간에 해당한다

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 누를 때마다 새 설명 하나를 읽는다 (Priority: P1)

학습자가 0.5초 진행을 한 번씩 누를 때마다 표가 한 줄 늘고, 표 아래에서 새 설명 하나만 읽는다.

**Acceptance Scenarios**:

1. **Given** 5단계에서 발사함, **When** 1번 누름, **Then** 방금 조각 문장 → 표(1줄) → 🤔 의문 → 이유 상자만 보인다
2. **When** 2번째 누름, **Then** 방금 조각 문장 → 표(2줄) → "vy가 매번 약 4.9씩…"만 보이고, 의문·이유 상자는 없다
3. **When** 3번째 누름, **Then** 방금 조각 문장 → 표(3줄) → "맨 오른쪽 칸은…이게 적분이에요."만 보인다
4. **When** 4번째 누름, **Then** 방금 조각 문장 → 표(4줄) → "더 눌러 봐도 되고…"만 보이고 다음으로 넘어갈 수 있다
5. **When** 12번째까지 누름, **Then** 방금 조각 문장 → 표 → 음수 안내 → "더 눌러 봐도 되고…"
6. 위 각 경우에 영어로 바꿔도 같은 덩어리가 같은 순서로 보인다

### Edge Cases

- 누른 뒤 언어를 바꿈: 같은 횟수의 설명이 그 언어로 보인다
- 5단계를 나갔다 다시 들어오거나 다시 발사: 표와 횟수가 처음부터 시작되므로 1번 설명부터 다시 나온다 (지금 동작 그대로)
- 발사 전 안내, 발사 직후 안내("이제 0.5초 진행 ⏭을 눌러 보세요.")는 바뀌지 않는다
