# Quickstart: 튜토리얼 실험 단계 각도 버튼 상태 확인

## 자동 확인

```bash
pnpm check                                   # 타입 검사 + 의존 규칙 + 단위 테스트 (tests/angle-buttons.test.ts 포함)
pnpm exec playwright test e2e/angle-buttons.spec.ts   # 15단계 상태·갱신·접근성·360px
pnpm test:e2e                                # 전체 (이전 비교 약 8분)
```

`pnpm preview`를 따로 띄웠다면 끝낼 때 4173 포트의 node 프로세스까지 종료한다.

## 손으로 확인

1. `pnpm dev` → http://localhost:5173/episodes/01-calculus-howitzer/ → 튜토리얼 열기 → 15/22 "실험: 각도만 바꿔 보기"까지 진행
2. 슬라이더가 45°면 45° 버튼만 진한 채움 (현재)
3. 30° 버튼 → 발사 → 착탄 후 30° 버튼이 회색 채움, 눌러도 반응 없음, Tab 이동에서 건너뜀
4. ± 버튼·드래그·키보드 화살표로 각도를 바꾸면 "현재" 표시가 곧바로 따라감 (50.5°면 현재 버튼 없음), 화면이 튀지 않음
5. 30·40·45·50으로 4발 → "40°·45°·50°는 거리가 거의 같죠?" 문장 (60°를 언급하지 않음). 한 발 더 60° → 첫 줄 문장(30°·60° 포함)
6. 개발자 도구 360px → 버튼 5개 한 줄, 각 44px 이상, 가로 스크롤 없음
7. 밝은·어두운 테마, 흑백(렌더링 → 색각 에뮬레이션)에서 세 상태 구분
8. 언어 전환 → 버튼 상태 유지, 관찰 문장·접근성 이름이 영어로
