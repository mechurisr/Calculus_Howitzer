# Answers and Verification: 튜토리얼 실험 단계 각도 버튼 상태

검토 에이전트는 `spec.md`의 V1을 먼저 직접 푼 뒤 이 파일과 비교할 것.
이 미션은 계산을 바꾸지 않는다(C-001). 정답은 화면 배치 확인 하나다.

## V1. 360px 화면의 카드 안쪽 폭과 버튼 5개 배치

- Answer: 카드 안쪽 폭은 **302 px**(오버레이 스크롤바, 휴대폰) 또는 **287 px**(카드가 세로로 넘쳐 클래식 15 px 스크롤바가 생길 때, 데스크톱 Chromium의 360 px 창). 두 경우 모두 44 px 이상 버튼 5개가 8 px 간격으로 한 줄에 들어간다. 버튼 폭 상한은 **51.0 px**(287 px) / 54.0 px(302 px)
- Derivation:
  - 카드 폭 = min(560, 360 − 24) = 336 px (`engine/src/tutorial/tutorial.css` `.tut{width:min(560px,calc(100% - 24px))}`. 카드는 `position:fixed`로 `body`에 붙으므로 100%는 뷰포트 폭)
  - 안쪽 폭 = 336 − 2·1(테두리 좌우) − 2·16(안쪽 여백 좌우) = **302 px** (`border:1px`, `padding:14px 16px`. `engine/src/ui/theme.css`의 `*{box-sizing:border-box}`라 336 px 안에 테두리·여백이 포함됨). 15단계는 표 때문에 카드가 `max-height:48vh`를 넘어 `overflow:auto` 스크롤바가 생기며, 클래식 스크롤바(15 px)면 302 − 15 = **287 px**
  - 최소 배치: 5·44 + 4·8 = 252 px ≤ 287 → 여유 35 px
  - 폭 상한: (287 − 4·8) / 5 = **51.0 px**, (302 − 4·8) / 5 = 54.0 px. 지금 버튼("30°", 글자 약 22~26 px + 좌우 여백 12·2 + 테두리 1·2 ≈ 48~52 px)은 상한 경계에 걸려 글자 폭 기준으로는 287 px에서 넘칠 수 있다 → 폭을 카드 내용 폭에서 나눠 갖게 해야 함 (NFR-001)
  - 높이: 지금 `.tut-body .act`는 8 + 8 + 15·1.55(= 23.25) + 2 = **41.25 px**로 44 px에 2.75 px 모자람 → NFR-001
  - (참고, 범위 밖) 320 px이면 안쪽 262 / 247 px → 상한 46.0 / 43.0 px로 클래식 스크롤바에서는 44 px를 유지할 수 없음. 헌장 기준(360 px) 밖이라 두 줄 허용
- Verification: Playwright 360 px에서 15단계 버튼 5개의 경계 상자가 각각 44×44 이상, 모두 같은 `top`, 이웃 사이 간격 ≥ 8, `scrollWidth ≤ clientWidth` (NFR-001). 기존 모바일 390 px도 같이 확인

## 상태 규칙 확인표 (FR-001~FR-004)

슬라이더 θ, 기록된 각도 집합 E에 대해 버튼 a의 상태:

| 조건 | 상태 |
|---|---|
| a ∈ E | 쏜 각도 (비활성) — θ와 상관없이 |
| a ∉ E, θ = a | 현재 |
| 그 밖 | 보통 |

- 겹치면 쏜 각도만 보인다. 이때 "현재" 표시는 어느 버튼에도 없다 (US2-4)
- 예: E = {30, 45}, θ = 45 → 30 쏜 각도, 40 보통, 45 쏜 각도, 50 보통, 60 보통 ("현재" 없음)
- 예: E = {30, 37.5}, θ = 50 → 30 쏜 각도, 50 현재, 나머지 보통 (37.5는 버튼 없음)

## 관찰 문장 선택 (FR-007)

4발 기록 후, M = {40, 45, 50} ⊆ E, P = {30, 60} ⊆ E:

| M | P | 문장 |
|---|---|---|
| 참 | 참 | 40·45·50 + 30·60 (지금 문장 그대로) |
| 참 | 거짓 | 40·45·50만 |
| 거짓 | 참 | 30·60만 |
| 거짓 | 거짓 | 표에서 비교 |

- 이전 비교 테스트의 자동 진행은 30→40→45→50 순서라 E = {30, 40, 45, 50} → M 참, P 거짓 → "40·45·50만" 문장. legacy는 지금 문장이므로 C-003 ②의 허용 차이가 실제로 생긴다
- 각도 버튼 4개로 가능한 조합 5가지: {40,45,50,60}·{30,40,45,50} → M만, {30,40,45,60}·{30,40,50,60}·{30,45,50,60} → P만. 버튼만 쓰면 "둘 다"는 5발이 있어야 하므로 나오지 않는다 (슬라이더로 37.5° 등을 섞으면 4발에서 "그 밖"도 가능)
